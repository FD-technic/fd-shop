# FD-Shop

Fullstack e-commerce application built as a long-term portfolio project.

## Project Goals

This project is created for:

- learning backend and frontend development
- improving Java and Spring Boot skills
- working with databases and REST API
- building a real portfolio project
- possible future production deployment

## Technologies
### Backend
- Java
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Maven

### Frontend
- React
- Vite
- JavaScript

### Project Structure
```
 fd-shop/
  ├── backend/
  └── frontend/
```
## Current Status

Project is currently in early development.

## Planned features:

- product management
- shopping cart
- order system
- admin panel
- user authentication
- responsive frontend
